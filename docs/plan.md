# LegionCore Lab Plan

## Goal
Turn LegionCore into a DevOps training project with:
- Docker-based local environment
- automated database bootstrap
- reproducible setup
- CI/CD pipeline
- deployable stack for VPS

## Planned stages
1. Prepare repository structure
2. Add MySQL in Docker Compose
3. Add database init scripts
4. Add Dockerfile for core build
5. Add GitHub Actions CI
6. Add deployment workflow
7. Add monitoring and backups
